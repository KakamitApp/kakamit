App Release Notes

Kakamit.com is a free tool to track Gut Health. Data is stored ONLY on your device for maximum privacy. Use offline & export data.

🎉 Version 1.0

Released: 16.8.2026

📖 Public Audit Repository

  • Open source & auditable: Kakamit's source code is now published as a public, MIT-licensed audit repository so anyone can verify our privacy and security model. The DGBS concept, name, and brand remain reserved by Kakamit.

💨 Version 0.8

Released: 16.8.2026

💨 Clearer DGBS Icons

  • Refreshed rating icons: Based on user feedback, the Daily Gas Burden Scale (DGBS) icons have been redesigned to be clearer and easier to tell apart, making your daily 1–5 rating quicker and more intuitive.

⚡ Optimizations & Security

  • Performance optimizations: Further under-the-hood improvements for a faster, smoother experience.
  • Security improvements: Internal security updates and dependency upgrades to keep your local-only data safe.

📊 Version 0.5.2

Released: 3.7.2026

📊 CSV Export & Import

  • Spreadsheet-friendly export: Alongside JSON, you can now export your data as a CSV file—open it directly in Excel, Numbers, or Google Sheets to chart and analyze your entries yourself.
  • CSV import too: Import a CSV file back into the app with the same safe, merge-by-ID behavior as JSON. The import button auto-detects whether your file is JSON or CSV, and invalid rows are skipped and reported. Everything stays on your device.

📥 Version 0.5.1

Released: 3.7.2026

📥 JSON Data Import

  • Restore & merge your data: You can now import a previously exported JSON file directly from the entry list. Re-importing your own export safely restores or updates records without creating duplicates—existing entries are matched by ID and merged.
  • Safe by design: Invalid or unrecognized rows are skipped and reported back to you, and older data formats are migrated automatically. As always, everything stays on your device.

⚡ Technical Improvements

  • Type-safe builds: Added strict TypeScript checking to the build pipeline, catching potential errors before they can ship.
  • Faster startup: Secondary pages are now code-split and loaded on demand, shrinking the initial app bundle for a quicker first load.
  • Cleaner internals: Removed dead code and resolved build warnings for a leaner, more maintainable app.

🌟 Version 0.5.0

Released: 2.7.2026

📄 Printable Doctor Report

  • New Report Page: You can now generate a printable summary of your gut health data directly from your browser. This includes clinical summaries, weekly averages, and data distributions—perfect for printing or saving as a PDF for your doctor.

🌍 Localization & Technical Improvements

  • Localization updates: General improvements and key syncing across all 13 supported languages to ensure a consistent experience for everyone.
  • Technical improvements: Under-the-hood bug fixes, code cleanup, and performance optimizations to keep the app running smoothly and privately.

🔥 Version 0.4.0

Released: 25.06.2026

📊 Logging Streak

  • Daily logging streak: The app now tracks consecutive days you've logged entries. A streak badge on your home screen shows your current streak and celebrates milestones with toast notifications.
  • Milestones: Get recognized at 7, 14, 30, 60, 90, 180, and 365 days. Beat your personal record and the app lets you know.
  • Fully localized: Streak messages available in all 13 supported languages.

⚡ Version 0.3.0

Released: 12.02.2026

🚀 Performance & Storage Overhaul

  • Migration to IndexedDB: We have upgraded our local storage engine to IndexedDB. This allows for much larger datasets, better data integrity, and faster retrieval as your history grows.
  • Significant Speed Boost: Refactored core data-handling logic to reduce latency. The app now feels snappier, especially when loading long-term gut health trends.
  • Background Optimization: Improved the way data is indexed, ensuring that your privacy-focused, local-only database runs efficiently even on older devices.

✨ New Feature: DGBS Tracker (Daily Gas Burden Scale)
