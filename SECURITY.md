# Security Policy

## Reporting a Vulnerability

Please report security or privacy issues privately before public disclosure.

Please report privately using **GitHub Security Advisories**:
[Report a vulnerability](https://github.com/KakamitApp/kakamit/security/advisories/new).

Please allow a reasonable time for a fix before any public disclosure.

## Scope

In scope:

- Data leakage
- Unexpected network requests
- IndexedDB data handling issues
- Export/import validation issues
- PWA/service worker caching issues
- Build/dependency security issues

Out of scope:

- Medical interpretation of user data
- Feature requests
- General translation quality issues
